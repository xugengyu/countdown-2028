# Time Until Liftoff

A minimal launch countdown showing days, hours, minutes, and seconds until **November 15, 2028 at midnight Pacific time** (America/Los_Angeles, UTC-8).

Live site: https://xugengyu.github.io/countdown-2028/

The background is an eight-second loop of an upright Falcon 9 venting vapor before launch, excerpted from NASA's Demo-2 camera footage. See [asset provenance](ASSET-SOURCE.md).

The background can be paused and automatically starts as a still image for visitors who prefer reduced motion. The countdown stops at zero and displays LIFTOFF.

This is a static site with no build step or dependencies. GitHub Pages publishes the root of the main branch. To preview locally, serve this directory with any static HTTP server.
